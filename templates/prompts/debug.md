# @debug

Systematically find the root cause of a bug.

1. Restate the observed vs. expected behavior.
2. Form the smallest reproduction.
3. Locate the failing code path; read it, don't guess.
4. Identify the root cause (not just the symptom).
5. Propose the minimal fix and a test that would have caught it.

Quote the exact error. Do not change unrelated code.
